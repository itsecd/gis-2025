# Лабораторная работа №3

## Совместный анализ данных с Overture Maps и построение тематической карты

### Цель

Интегрировать локальные здания из GeoJSON, полученного в ЛР1, с облачным набором Overture Maps Buildings, выполнить пространственный анализ в DuckDB, сформировать итоговый слой `overture.geojson` и визуализировать его в клиенте OpenLayers с помощью Mapbox Style.

---

## Запуск анализа DuckDB

Запустить обработку:
```bash
python scripts/run_analysis.py
```

Скрипт выполняет следующие действия:

1. загружает `data/input.geojson` в таблицу `user_buildings`;
2. вычисляет bbox участка;
3. подключается к Overture Maps Buildings GeoParquet по S3;
4. определяет партиции, пересекающиеся с bbox;
5. загружает здания Overture только из нужных партиций;
6. классифицирует объекты по полю `source_type`:
   - `my` — объект пересекается с моими зданиями;
   - `osm` — источник объекта OpenStreetMap;
   - `ml` — остальные объекты, полученные из ML/других источников;
7. сохраняет результат в `client/public/overture.geojson`.

Если интернет или доступ к Overture Maps недоступен, можно сформировать демонстрационный слой только из локальных зданий:

```bash
python scripts/run_analysis.py --offline-fallback
```

---


## Визуализация

Клиент использует:

- OpenLayers для отображения карты;
- `ol-mapbox-style` для применения Mapbox Style;
- локальный файл `/overture.geojson` без GeoServer.

Цветовая схема по `source_type`:

| source_type | Цвет | Значение |
|---|---|---|
| `my` | зелёный | пересечение с пользовательскими зданиями |
| `osm` | синий | источник OpenStreetMap |
| `ml` | оранжевый | ML/другие источники |
